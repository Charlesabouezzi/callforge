# ⬡ CallForge

**AI-powered sales training platform.** Reps practice live demo calls with AI avatars trained on your company playbook. Real-time scoring, manager dashboards, and mission assignments.

## What it does
- Sales reps log in and practice discovery, demo, and negotiation calls against AI prospects
- AI avatars are trained on your actual call transcripts and product info
- Each call is scored across 5 skill categories with a coach's debrief
- Managers assign specific practice missions to reps based on weaknesses
- Full team leaderboard and AI-generated rep performance reports

## Tech Stack
- React (frontend)
- Anthropic Claude API (AI prospect & scoring engine)
- Vercel (hosting)

## Getting Started

```bash
npm install
npm start
```

## Deploy
Connect this repo to Vercel and it deploys automatically on every push.
